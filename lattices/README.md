# Lattices

This folder contains the results of the cell optimisation studies and the different RCS arc lattice configurations developed throughout the project. It includes the lattice versions used for the different stages of the Muon Collider studies and reports.

### Cell optimisation results

- **`latex_table_CF/`**: Optimisation results for combined-function cells.
- **`latex_table_hyb_qd/`**: First version of the optimisation results for FODO and hybrid FODO (HFODO) cells.
- **`latex_table_hyb_qd_v2/`**: Final version of the optimisation results for FODO and hybrid FODO (HFODO) cells.

### Arc lattice configurations

- **`lattice_preliminary_ESPPU/`**: Lattice configurations prepared for the preliminary ESPPU report.
- **`lattice_04_25/`**: First set of 8-arc RCS lattices (April 2025).
- **`lattice_08_25/`**: Set of RCS1 lattices with varying numbers of arcs, from 8 to 28 (August 2025).
- **`lattice_consolidated_ESPPU/`**: Lattice configurations prepared for the consolidated ESPPU report.
- **`lattice_final_report/`**: Lattice configurations used for the final HEC report.

### Scripts

- **`convert_inj2ext`**: Script to convert an injection lattice into its corresponding extraction lattice. Particularly useful for hybrid RCS configurations.
