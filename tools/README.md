# Tools

This folder contains miscellaneous utility functions used across the different parts of the project.

- **`calcul_fodo_para.py`**: Computes basic FODO cell parameters.
- **`help_optics_para.py`**: Extracts and saves optics parameters from an Xsuite line.
- **`load_file.py`**: Utility functions to load files in different formats.
- **`save_para_rcs.py`**: Saves RCS parameters in the format required by the `RingGeometry` class.
- **`xsuite_to_madx.py`**: Small script to convert an Xsuite line into MAD-X format.
